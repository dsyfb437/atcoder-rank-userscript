# AtCoder 多场排名筛选

用户脚本在 AtCoder 比赛榜单页加入「多场排名筛选」面板。填入比赛 ID 或链接，并为每场指定起止名次，即可查看符合所有条件的用户名并导出 TXT。并列选手按 AtCoder 榜单提供的名次筛选。

## 安装和使用

1. 在 Tampermonkey 或 Violentmonkey 中导入 `atcoder-ranking-filter.user.js`。
2. 在浏览器中正常登录 AtCoder，打开一场比赛的榜单。
3. 展开「多场排名筛选」，编辑或添加比赛，点击「筛选交集」。

脚本只在 AtCoder 榜单页运行，使用浏览器已有的同站登录会话。用户名、筛选条件和榜单结果全部在当前页面处理。每场比赛的榜单在当前页面缓存，刷新页面后会重新获取。脚本源码采用 MIT 许可证。
